# Probably Stolen-Skip

简体中文 | [English](README.en.md)

**深空当铺：允许跳过对话**，作者 Clemm，当前版本 **0.1.2**，目标游戏版本 **0.46D**。

为交易 NPC 在开放买卖、折扣等操作前的开场对白提供平滑加速、过渡跳过和自动跳过。

## 使用

- 默认按住 **F6** 加速，松开后平滑恢复。加速最高为 6 倍，并带快进提示和对白框弹性反馈。
- 默认按下 **F7** 跳过当前交易开场，使用短时全屏黑色淡出淡入。
- 快捷面板中的“自动跳过前置对话”初始关闭。开启后，当前存档已遇见的 NPC 可自动跳过开场，首遇时仍可手动加速或跳过。
- 首遇复用原版按 NPC 类型保存的到访历史，安装前的记录也参与判断。新存档各自判定，同类随机头像共用该类型记录。
- 面板显示实际键位。首次运行会避开原版与已通过官方选项登记的 MOD 占用，并提示可识别的绑定冲突。
- 点击面板的快捷键设置入口进入原版选项，修改带“深空当铺：允许跳过对话”标识的两项绑定。
- 面板关闭后，可在原版选项的“对话”分区开启“显示深空当铺：允许跳过对话面板”。
- 输入文字、控制台获得焦点、原版设置或 ESC 暂停菜单打开、鼠标停在快捷面板上时，暂停对白控制。将鼠标移出面板即可继续。

对白动作、结束回调、交易、折扣、任务与奖励继续由原版流程处理。玩家选项交由玩家操作。

## 安装

1. 从本仓库 Releases 下载 `DialogueFlow-0.1.2.zip`。
2. 解压后将完整的 `dialogue_flow` 文件夹放入游戏安装目录的 `Mods` 文件夹。
3. 确认目录结构为 `Mods/dialogue_flow/manifest.xml` 与 `Mods/dialogue_flow/DialogueFlow.dll`。
4. 在游戏模组菜单中审核并启用此 MOD，再重启游戏。

更新时先退出游戏并备份旧的 `Mods/dialogue_flow`，再复制新版完整文件夹。Steam 工坊订阅版与手动安装版请统一使用一个来源，便于确认实际加载版本。

移除前在模组菜单停用并重启游戏，再删除 `Mods/dialogue_flow`。自动跳过与键位偏好保存于本 MOD 的官方配置中，NPC 到访记录由原版存档管理。

发布包和版本说明见 [Releases](https://github.com/ukpkmkk91/Probably-Stolen-Skip/releases)。

## 验证与已知边界

0.1.2 发布内容通过无警告编译、1969 项运动断言、103 个方法的官方扫描器严格离线整目录检查及发布文件一致性检查。现有发布包使用 Roslyn 编译。

0.1.0 的游戏测试覆盖代表性手动跳过、自动复访、首遇保护、存读档、新档隔离、跨档返回、改绑与原版占键提醒。0.1.1 另行验证 ESC 暂停菜单内的输入保护及恢复后的对白操作。0.1.2 为显示名称与版本更新，游戏内新名称和长标题布局尚未单独实测。

- 默认右上快捷面板可能遮挡部分原版交易窗标题。面板已接入官方拖动接口，实际拖动效果尚待确认。
- 持续按住 F6 的主观弹性手感仍待进一步确认。
- 外部 MOD 的实际占键场景尚未穷举，冲突检测范围为原版及通过官方选项公开登记的绑定。
- 全部 NPC、任务变体、交易开场链中的玩家选项正例、精确淡出中途退出与快速重复输入尚未完整覆盖。

## 从源码构建

源码工程目标为 `netstandard2.1`。准备支持该目标的 .NET SDK，以及本机安装的目标版本游戏，再执行以下 PowerShell 命令。示例中的游戏路径请替换为自己的安装路径。

```powershell
dotnet build DialogueFlow.csproj -c Release '-p:GameDir=C:\Games\Probably Stolen'
```

生成的 DLL 位于 `bin/Release/netstandard2.1/DialogueFlow.dll`。创建 `dialogue_flow` 目录，将 DLL、根目录的 `manifest.xml` 和玩家说明一同放入，再按安装步骤处理。编译引用由 `GameDir/Probably Stolen_Data/Managed` 提供。

上述 SDK 构建命令尚未在本机实测，现有发布包使用 Roslyn 与游戏库构建。自行构建的产物需要重新进行扫描和运行验证。
